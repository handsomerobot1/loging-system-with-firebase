🔐 Firebase Login System (Kotlin + XML)
This is a simple Android application that implements a login system using Firebase Authentication. Users can register, log in, and log out using email and password.

🛠️ Tech Stack
Kotlin (Android)
XML Layouts
Firebase Authentication
Android Studio

🚀 Features
User Registration (Email & Password)
User Login
